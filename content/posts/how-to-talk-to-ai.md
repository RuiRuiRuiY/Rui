# 如何与AI有效对话

很多人觉得 AI 不听话、答非所问，其实问题往往出在**提示词（Prompt）**上。这篇文章分享一些经过验证的 Prompt 技巧，帮助你获得更好的 AI 回答。

## 核心原则：清晰具体

AI 不是读心术大师。如果你想要好答案，就要给好问题。

### ❌ 不好的提问
> 帮我写个代码

### ✅ 好的提问
> 用 Python 写一个函数，接收一个整数列表，返回其中能被3整除的所有数字，要求时间复杂度为 O(n)。

## 技巧一：赋予角色

让 AI 扮演特定角色，能激活它相关的知识模式。

```
你是一位资深 Python 工程师，有10年后端开发经验。
请 review 下面的代码，指出潜在问题和改进建议：

[粘贴代码]
```

## 技巧二：提供上下文

背景信息越丰富，AI 的回答越精准。

```
我正在开发一个面向大学生的在线学习平台。
目标用户：18-25岁，主要使用移动端。
技术栈：Next.js + Tailwind CSS

请推荐5个适合这个项目的 UI 组件库，并说明理由。
```

## 技巧三：指定输出格式

明确你想要的回答结构。

```
请对比 React 和 Vue 的以下方面：
1. 学习曲线
2. 生态系统
3. 就业市场

每个方面用「优点/缺点」两列表格呈现，最后给出选择建议。
```

## 技巧四：Few-Shot 示例

给 AI 几个例子，让它照猫画虎。

```
请将下面的产品描述改写得更吸引人：

示例1：
输入：一款无线耳机
输出：告别线缆束缚，沉浸纯粹音质——新一代真无线耳机，让音乐随行而动。

示例2：
输入：一辆电动自行车
输出：城市通勤新选择，一次充电续航80公里，轻松穿梭大街小巷。

现在改写：
输入：一款智能手表
输出：
```

## 技巧五：分步骤思考

对于复杂问题，让 AI 一步步来。

```
请逐步分析以下代码的性能瓶颈：

[粘贴代码]

分析步骤：
1. 识别所有的循环结构
2. 计算每个循环的时间复杂度
3. 找出嵌套循环或重复计算
4. 给出优化建议
```

## 常见错误

### 1. 一次性塞太多信息

错误：在一个 Prompt 里包含5个不同的问题。
修正：分批提问，或明确标注「请分别回答以下5个问题」。

### 2. 期望 AI 知道你不知道的

错误：「用我们公司的 API 调一下这个数据」。
修正：提供 API 文档链接或相关说明。

### 3. 没有验证结果的意识

AI 会犯错，重要信息务必交叉验证。

## 进阶：构建可复用的 Prompt 模板

把常用的 Prompt 结构保存下来：

```markdown
## 代码解释模板

请解释下面这段代码：
- 整体功能是什么
- 每个函数的作用
- 关键逻辑逐行解释
- 潜在的风险或改进点

[粘贴代码]
```

## 总结

写好 Prompt 的核心是**换位思考**：假设对方是一个聪明但无所不知的助手，你需要给出多少信息才能让任务被正确执行？

多加练习，你会发现 AI 的能力边界远比初体验时宽广。
